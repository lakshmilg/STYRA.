# STYRA — Fashion Landing Page

STYRA is a responsive fashion landing page built with React, designed as a modern brand experience focused on bold visuals, clean layouts, and interactive UI elements.

> **Note:** This is a frontend showcase project. Forms are demonstration-only and do not persist data.

## Features

- Sticky navigation with dynamic scroll behavior
- Custom toast notification system
- Contact and newsletter forms with client-side validation
- Smooth hover effects and scroll reveal animations
- Responsive multi-section layout

---

## Tech Stack

- React
- Vite
- Tailwind CSS

---

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

### Production build

```bash
npm run build
```

## Notes

- Forms are UI demonstrations only
- No backend or database integration
- Social links are included for branding purposes
